What is Lakebase?
AttributeDetails
ProductDatabricks Lakebase — Fully managed PostgreSQL database natively integrated into the Databricks platform
PurposeBrings OLTP (transactional, low-latency) capabilities alongside Lakehouse OLAP (analytical) workloads
ScalingAuto-scales from 0.5 to 64 Compute Units (CU). Each CU = 2 GB RAM. Scale-to-zero when idle.

Current State vs. Proposed State

❌ Current Architecture (Problems)

  • • Config stored in /tmp JSON files — wiped on every redeployment
  • • Sessions in in-memory dicts — lost on app restart
  • • 200ms+ latency for config lookups via Delta/SQL Warehouse
  • • No multi-instance support — state diverges across replicas
  • • Audit logs batched (not real-time), no ACID guarantees
  • • Manual credential management for external DBs
→

✅ With Lakebase (Solutions)

  • • Config in managed Postgres — persists across all deployments
  • • Sessions in durable tables — survive restarts & crashes
  • • Sub-5ms reads — 10-50x improvement
  • • Shared state across all app instances (HA-ready)
  • • Transactional audit log with real-time ACID commits
  • • Zero-credential — auto-injected OAuth tokens
