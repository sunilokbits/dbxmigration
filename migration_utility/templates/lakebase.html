📚 What is Lakebase?

Lakebase is Databricks' fully managed PostgreSQL database, natively integrated into the Databricks platform. It brings OLTP (transactional) capabilities alongside your Lakehouse OLAP (analytical) workloads.

⚡ Low-Latency Transactions

Sub-10ms reads/writes for app state, user sessions, config, and metadata — unlike Delta tables which have 100ms+ latency.

🔄 Auto-Scaling

Scales from 0.5 to 64 Compute Units (CU) automatically based on demand. Each CU = 2 GB RAM.

💤 Scale-to-Zero

When idle, compute scales to zero — zero cost for inactive databases. Resumes in seconds.

🎯 Unity Catalog Integration

Automatic UC registration — query Lakebase tables from notebooks, SQL warehouses, and pipelines via standard SQL.

🔌 Databricks Apps Native

First-class integration: connection details injected as environment variables (PGHOST, PGDATABASE, PGUSER). Zero credential management.

🔀 Change Data Feed

Row-level changes from Postgres stored as Delta tables — ideal for audit trails, downstream pipelines, and compliance.

✔ Why Lakebase for DBXConnect?

🔴 Current Architecture (Problems)

  • JSON files on /tmp — Config (genie_spaces, mcp_endpoints) lost on every redeployment
  • In-memory dicts — MCP sessions (_mcp_sessions) lost on app restart
  • No multi-instance support — If app scales to 2+ replicas, sessions/state diverge
  • Delta tables for app state — High latency (200ms+) for simple config reads
  • No real-time audit — Audit log writes to Delta are batched, not transactional
  • File-based user roles — Cannot enforce ACID constraints on role assignments

🟢 With Lakebase (Solutions)

  • Persistent config storage — Survives all deployments, zero file I/O
  • Durable sessions — MCP sessions stored in Postgres, survive restarts
  • Shared state across replicas — All instances read/write same DB
  • Sub-5ms config reads — Postgres optimized for point lookups
  • Transactional audit log — Every action committed with ACID guarantees
  • Proper RBAC tables — Foreign keys, constraints, and indexes for user management
Key Benefit: Lakebase solves the #1 pain point in DBXConnect today — configuration loss on redeployment. Your Genie spaces, MCP endpoints, user preferences, and session state will persist permanently.

Common Errors During Integration

🔴 psycopg2 not installed

Add psycopg2-binary==2.9.9 to requirements.txt. The binary wheel avoids libpq build issues in the container.

Easy Fix

🔴 PGHOST not set

Add Lakebase as a resource in app.yaml. The platform auto-injects PG* env vars when the resource is declared.

Easy Fix

🟠 Token refresh race condition

Multiple threads calling generate_database_credential() simultaneously. Use a lock + shared token with 15-min TTL.

Moderate

🟠 SSL certificate errors

Always use sslmode='require'. The Lakebase endpoint enforces TLS; self-signed cert issues don't apply.

Easy Fix

🔴 Permission denied on schema

The app's service principal needs schema ownership. Run GRANT ALL ON SCHEMA app_config TO app_role; during setup.

Moderate

🟠 Connection timeout on first request

If scale-to-zero is enabled, first connection takes 3-5s. Add a startup health-check that warms the connection pool.

Easy Fix

💻 Implementation: Connection Module

Below is the proposed db.py module that handles Lakebase connectivity with auto-refresh:

# migration_utility/routes/db.py import os, uuid, time, threading from sqlalchemy import create_engine, text, event from sqlalchemy.pool import QueuePool from databricks.sdk import WorkspaceClient _w = WorkspaceClient() _lock = threading.Lock() _token = None _token_ts = 0 _TOKEN_TTL = 900 # Refresh every 15 min (token valid 1hr) def _get_engine(): pg_url = (f"postgresql+psycopg2://" f"{os.environ['PGUSER']}:@" f"{os.environ['PGHOST']}:" f"{os.environ.get('PGPORT','5432')}/" f"{os.environ['PGDATABASE']}") engine = create_engine( pg_url, poolclass=QueuePool, pool_size=5, max_overflow=10, pool_pre_ping=True, pool_recycle=1800 ) @event.listens_for(engine, "do_connect") def _inject_token(dialect, conn_rec, cargs, cparams): global _token, _token_ts with _lock: if _token is None or time.time() - _token_ts > _TOKEN_TTL: cred = _w.database.generate_database_credential( request_id=str(uuid.uuid4()), instance_names=[os.environ['PGDATABASE']] ) _token = cred.token _token_ts = time.time() cparams["password"] = _token cparams["sslmode"] = "require" return engine engine = _get_engine() def get_db(): """Return a connection context manager.""" return engine.connect()

Create init_db.py — Schema Migration Script

Create a startup script that ensures all required tables exist. This runs on every app startup with IF NOT EXISTS for idempotency.

# File: /apps/DBXConnect/migration_utility/init_db.py from routes.db import get_db from sqlalchemy import text def run_migrations(): """Create schemas and tables if they don't exist.""" with get_db() as conn: conn.execute(text("CREATE SCHEMA IF NOT EXISTS app_config")) conn.execute(text("CREATE SCHEMA IF NOT EXISTS app_state")) conn.execute(text("CREATE SCHEMA IF NOT EXISTS app_auth")) conn.execute(text("CREATE SCHEMA IF NOT EXISTS app_audit")) conn.execute(text(""" CREATE TABLE IF NOT EXISTS app_config.genie_spaces ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), space_id VARCHAR(64) NOT NULL UNIQUE, name VARCHAR(255) NOT NULL, description TEXT, created_at TIMESTAMPTZ DEFAULT now(), created_by VARCHAR(255) ) """)) conn.execute(text(""" CREATE TABLE IF NOT EXISTS app_config.mcp_endpoints ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), endpoint_url TEXT NOT NULL UNIQUE, name VARCHAR(255) NOT NULL, type VARCHAR(20) DEFAULT 'mcp', created_at TIMESTAMPTZ DEFAULT now() ) """)) conn.execute(text(""" CREATE TABLE IF NOT EXISTS app_state.mcp_sessions ( session_id VARCHAR(64) PRIMARY KEY, endpoint_url TEXT NOT NULL, mcp_session_hdr VARCHAR(255), tools JSONB, request_counter INTEGER DEFAULT 0, created_at TIMESTAMPTZ DEFAULT now(), last_used TIMESTAMPTZ DEFAULT now() ) """)) conn.execute(text(""" CREATE TABLE IF NOT EXISTS app_auth.user_roles ( user_email VARCHAR(255) PRIMARY KEY, role VARCHAR(20) CHECK (role IN ('admin','operator','viewer')), granted_by VARCHAR(255), granted_at TIMESTAMPTZ DEFAULT now() ) """)) conn.execute(text(""" CREATE TABLE IF NOT EXISTS app_audit.events ( id BIGSERIAL PRIMARY KEY, user_email VARCHAR(255), action VARCHAR(100) NOT NULL, entity VARCHAR(255), details JSONB, timestamp TIMESTAMPTZ DEFAULT now() ) """)) conn.commit() print("[init_db] All schemas and tables ready.")

Refactor genie.py — Replace File I/O with SQL

Update the _load_mcp_endpoints() and _save_mcp_endpoints() functions to use Lakebase instead of JSON files.

# File: /apps/DBXConnect/migration_utility/routes/genie.py # Replace the existing functions: from routes.db import get_db def _load_mcp_endpoints(): try: with get_db() as conn: rows = conn.execute(text( "SELECT id, endpoint_url, name, type FROM app_config.mcp_endpoints ORDER BY created_at" )).fetchall() return [{"id": str(r[0]), "endpoint_url": r[1], "name": r[2], "type": r[3]} for r in rows] except Exception: # Fallback to JSON if Lakebase unavailable return _load_mcp_endpoints_json() def _save_mcp_endpoint(name, endpoint_url): with get_db() as conn: conn.execute(text(""" INSERT INTO app_config.mcp_endpoints (endpoint_url, name) VALUES (:url, :name) ON CONFLICT (endpoint_url) DO NOTHING """), {"url": endpoint_url, "name": name}) conn.commit() def _delete_mcp_endpoint(ep_id): with get_db() as conn: conn.execute(text( "DELETE FROM app_config.mcp_endpoints WHERE id = :id" ), {"id": ep_id}) conn.commit()
